# Megara v2.0.0 실제 사용 인수 테스트 체크리스트

## 0. 목적과 판정 규칙

이 문서는 자동 테스트 재실행 목록이 아니라, 실제 사용자가 `v2.0.0`을 설치하고 Planning Core를 끝까지 사용할 수 있는지 확인하는 UAT(User Acceptance Test) 절차다.

- 대상 릴리스: [`v2.0.0`](https://github.com/the-agentic-world/megara/releases/tag/v2.0.0)
- tag object: `0151c363af61c27b9a2fc23724956cb7d2481a2b`
- peeled release commit: `b9d8ffbce9198f5377ad249cca9c673660bb167d`
- 현재 정책: 사용자의 명시적 결정에 따라 `v2.0.0` tag와 RDR은 cryptographically unsigned다. 서명 검증을 PASS로 기록하지 않는다.
- 자동 release evidence와 CI 성공은 사전 조건이다. 실제 host UX 성공을 대신하지 않는다.

각 항목은 다음 상태 중 하나로 기록한다.

- `PASS`: 기대 결과와 증거가 모두 존재한다.
- `FAIL`: 기대 결과와 다르거나 데이터 손상·무단 변경이 발생했다.
- `BLOCKED`: 외부 의존성 또는 환경 문제로 실행할 수 없다.
- `NOT RUN`: 아직 실행하지 않았다. 최종 PASS에는 사용할 수 없다.
- `N/A`: 조건부 항목이며 조건이 발생하지 않았다는 근거가 있다.

최종 판정:

- [ ] `P0` 항목 전부 PASS
- [ ] 선택한 지원 플랫폼별 `P1` 항목 전부 PASS
- [ ] 실행한 `P2` 항목에 미해결 FAIL 없음
- [ ] 실패 로그와 성공 재실행 로그를 모두 보존
- [ ] 발견한 결함을 [GitHub Issues](https://github.com/the-agentic-world/megara/issues)에 등록
- [ ] 이 문서의 최종 결과표와 증거 위치 기록
